# Current features

- Public aircraft search, filters, details, ordered galleries and seller contact links.
- Public Markdown articles, header images and metadata.
- Responsive Next.js / Tailwind interface and server-side public data fetching.
- Owner-only OAuth content MCP with batch create, read, patch, publish/unpublish and delete operations.
- Supplied image imports, signed direct uploads and aircraft gallery management.

The previous admin pages, user/profile editor, legacy AI auto-population, generated article images and their dependencies were removed. Agents now prepare text and media outside the site and use the MCP to manage content. Payments, deposits, automated valuations and logbook analysis are not implemented.
